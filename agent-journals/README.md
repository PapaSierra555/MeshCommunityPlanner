# Agent Journals

Each agent maintains its own journal in this directory.

These journals are working notes, not the task source of truth. The task source of truth remains `../backlog.md`.

Rules:

- Append dated entries when an agent starts work, discovers important context, blocks, verifies behavior, or hands off work.
- Keep entries concise and factual.
- Do not rearrange or reprioritize `../backlog.md` from an agent journal.
- Agents may add concise notes to `../backlog.md` when needed, but only the Architect should restructure backlog sections or change execution order.
- Include touched files and verification commands when relevant.

Entry format:

```md
## YYYY-MM-DD - Task Name

- Status:
- Scope:
- Files touched:
- Findings:
- Verification:
- Handoff notes:
```
